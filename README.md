# KAIRide

Телеграм-бот для совместных поездок студентов КАИ: общежитие ↔ учёба. Организуешь поездку — остальные подсаживаются.

## Инструкция для пользователей

### Как начать

- **Добавьте бота** в Telegram (по имени/ссылке, которую вам дали).
- **Нажмите `Start`** или отправьте команду `/start`.
- Бот покажет приветственное сообщение и главное меню с кнопками:
  - **Создать поездку**
  - **Найти поездку**
  - **Мои поездки**
  - **Профиль**
  - **Помощь**

Все основные действия доступны как через кнопки, так и через команды (`/create`, `/search`, `/profile`, `/help` и т.д.).

---

### Создание поездки

1. В главном меню нажмите **«Создать поездку»** или отправьте команду **`/create`**.
2. Бот последовательно спросит:
   - **Тип транспорта**:
     - Личный транспорт
     - Такси
   - **Откуда**: выберите общежитие.
   - **Куда**: выберите учебное здание.
   - **День**: сегодня / завтра / другая дата.
   - **Время отправления**: в формате `ЧЧ:ММ` (например, `15:50`). Время — **московское**.
   - **Количество мест** (кроме водителя).
   - **Комментарий** (необязательно) — например, «заезд к магазину» или «поедем по набережной».
3. В конце бот покажет **экран подтверждения** со всеми данными.
4. Нажмите **«Подтвердить»**, чтобы создать поездку, или **«Изменить»**, чтобы начать заново.

После подтверждения:

- Поездка попадает в общий список поиска.
- Вам придут уведомления, когда к вам кто‑то присоединится.
- Если поездка создана **менее чем за 15 минут** до старта, бот сразу пришлёт напоминание (и за 5 минут — отдельное напоминание с кнопками для завершения).

---

### Поиск и запись в поездку

1. В меню выберите **«Найти поездку»** или отправьте **`/search`**.
2. Задайте фильтры:
   - Общежитие (откуда вы выезжаете).
   - Здание (куда нужно попасть).
   - День.
3. Бот покажет список подходящих поездок:
   - показываются только **активные** поездки;
   - поездки без свободных мест **не отображаются**;
   - свои же поездки вы в поиске **не увидите**.
4. Выберите нужную поездку и нажмите кнопку **«Присоединиться»**.

После присоединения:

- Организатор получит уведомление, что вы записались.
- Поездка появится в разделе **«Мои поездки»**.

---

### Мои поездки

Раздел **«Мои поездки»** показывает:

- **Активные поездки** (ещё не начались и не завершены).
- **Прошедшие поездки** (завершённые или отменённые).

Функциональность зависит от вашей роли:

- **Организатор**:
  - Удалить поездку.
  - Открыть чат поездки.
  - Завершить поездку и пройти опрос по участникам (кто опоздал, кто не пришёл).
- **Пассажир**:
  - Выйти из поездки.
  - Открыть чат.
  - Показать `@username` организатора.

Есть пагинация и нумерация, если поездок много.

---

### Напоминания о поездке

- **За 15 минут** до начала поездки:
  - Бот шлёт напоминание **всем участникам** (организатору и пассажирам).
- **За 5 минут** до начала:
  - Бот шлёт напоминание **организатору** с кнопками:
    - «✅ Поездка завершена»
    - «❌ Отменить поездку»

Если поездка создана:

- **меньше чем за 15 минут** — 15‑минутное напоминание приходит **сразу**;
- **меньше чем за 5 минут** — 15‑минутное + 5‑минутное с кнопками приходят **сразу**.

Время всегда считается по **Москве**.

---

### Чат поездки

У каждой поездки есть **отдельный чат** (виртуальный, внутри бота):

- Сообщения отправляются в бота и **рассылаются всем участникам** поездки.
- Можно делиться:
  - местом встречи;
  - временем выезда;
  - данными машины (марка, номер, цвет);
  - скриншотами заказа такси.

Есть команда **`/stop_chat`**, чтобы выйти из режима чата и вернуться в меню.

---

### Рейтинг и штрафы

У каждого пользователя есть **рейтинг от 0 до 5.00**:

- Стартовое значение — **5.00**.
- Рейтинг показывается в разделе **«Профиль»**.

Рейтинг меняется в следующих случаях:

- **Организатор завершает поездку** и заполняет опрос:
  - участник **опоздал** → −0.25;
  - участник **не пришёл вообще** → −0.75.
- **Пассажир такси** отвечает на вопрос:
  - «Машина была вызвана вовремя (±5 минут)?»
  - если жмёт **«Нет»**, организатору −0.5 (один раз от каждого пассажира).
- **Поздний выход из поездки** (менее чем за час до старта) → штраф пассажиру.
- **Поздняя отмена поездки организатором** (менее чем за час, при наличии записавшихся) → штраф организатору за каждого участника.

Рейтинг никогда не опускается ниже **0**.

---

### Профиль

Раздел **«Профиль»** показывает:

- ваш **рейтинг** (с точностью до двух знаков);
- сколько поездок вы **создали**;
- в скольких поездках вы **участвовали как пассажир**;
- сколько у вас **активных поездок** сейчас;
- с какой даты вы **пользуетесь сервисом**.

Открыть профиль можно:

- кнопкой **«Профиль»** в главном меню;
- командой **`/profile`**.

---

### Помощь

Если что‑то непонятно:

- нажмите **«Помощь»** в меню или отправьте **`/help`** — бот кратко объяснит основные функции и даст контакт для связи;
- можно написать в поддержку напрямую: **@emilbad**.


## Что нужно

- Docker и docker-compose
- Токен бота от [@BotFather](https://t.me/BotFather)

## Запуск

```bash
cp .env.example .env
# в .env прописать BOT_TOKEN
docker compose up --build
```

PostgreSQL и Redis поднимутся сами. Uvicorn слушает 8000 (FastAPI по факту только lifespan поднимает — бот живёт внутри приложения).

## Структура

```
app/
├── bot.py              # точка входа бота, reminders_worker
├── main.py             # FastAPI, lifespan: init_db + seed + start_bot
├── reminders.py        # напоминания за 15/5 мин (МСК)
├── database.py         # async engine, AsyncSessionLocal
├── core/
│   ├── redis.py        # Redis для FSM и ключей напоминаний
│   └── notifications.py
├── features/
│   ├── create_trip/    # создание поездки (FSM)
│   ├── search_trip/    # поиск
│   ├── my_trips/      # мои поездки, join/leave, чат, опросы, штрафы
│   ├── profile/        # рейтинг, статистика
│   └── support/        # /help
├── models/             # User, Trip, TripParticipant, Building, Dorm
├── db/                 # seed (здания, общежития)
└── constants.py        # BUILDINGS, DORMS
```

## Время

Пользователь вводит время в московском (24ч). В коде используется UTC+3.  
Напоминания считаются по Москве: воркер + проверка сразу при создании поездки (если меньше 15 мин — шлёт сразу).

## База

PostgreSQL 17, async через SQLAlchemy 2 + asyncpg. Миграции нет — `init_db()` создаёт таблицы при старте. Сид зданий и общежитий в `db/seed.py`, дергается из lifespan.

## Важно по рейтингу

Штрафы записываются только после `commit()`. Где меняется `user.rating` — там должен быть `session.commit()`, не только `flush()`. Иначе в профиле ничего не обновится.

## Локально без докера

```bash
python -m venv .venv
.venv\Scripts\activate   # win
pip install -r requirements.txt
```

В `.env` указать `POSTGRES_HOST=localhost`, `REDIS_HOST=localhost` — поднять postgres и redis локально, потом:

```bash
uvicorn app.main:app --reload
```
